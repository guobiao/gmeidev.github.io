# gmei.dev

[Homepage of Guobiao Mei](https://gmei.dev/)

Source repository for my personal website, hosted on GitHub Pages and built with [Jekyll](https://jekyllrb.com/) using the [`jekyll-theme-hacker`](https://github.com/pages-themes/hacker) theme.

## Structure

- `index.md` — Main homepage (contact, experience, education, and publications)
- `n1ui/` — Amateur radio page (FCC call sign N1UI)
- `april/` & `aiden/` — Family subpages
- `assets/` — Custom styles, images, and academic papers
- `_includes/` — Custom HTML head partial (Google Analytics)
- `_config.yml` & `CNAME` — Jekyll configuration and custom domain (`gmei.dev`)
